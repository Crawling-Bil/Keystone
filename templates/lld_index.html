What goes in each column
Site, Hostname, Model
Required. Site groups the chapters, hostname names them.
Role
Core Switch, Access Switch, Firewall, WLC, Router, Load Balancer. Decides the technology when there is no config.
Mgmt IP, SN
Shown in the management and device tables. Mgmt IP like 10.10.10.1/24.
Config
The config file name for this device. Blank = matched by hostname.
Rack, Rack Size, U, U Height
Draws the rack layout. U = lowest unit the device sits in. Size blank = 42, height blank = 1.
Status
New (installed now), Existing (old, removed) or Keep (stays, like a patch panel).
