Device captures

    Cisco IOS XE, NX-OS and the other vendors the Switch Analyzer reads. Nothing leaves this computer.

    Diagram
    SD-WAN sites on the L3 pages A hub router lists every branch in its BFD table. By default the page draws the sites you captured and one cloud for the rest ("+520 SD-WAN sites, not drawn"). Type site IDs, system IPs or part of a host name to draw exactly those sites, captured or not. After a build, the SD-WAN overlay tab lists every site with a tick box.
    Provider hints for the L3 views (optional) One rule per line: what = type provider. What can be a device and interface, an address or subnet, or a word that appears in a port description, VRF name or neighbor name. Type: mpls, internet, metro, lte or private. Without a rule the clouds come from descriptions, SD-WAN colours and neighbor names.
    Continue earlier work (optional)
    Add to a previous run Pick the topology.json of an earlier run. Its devices are kept; devices in the new captures replace the ones with the same serial number or hostname. You can also pick it with no new captures to rebuild with other options.
    Keep my layout Pick the topology.drawio you moved things in. Devices keep their position; new devices are placed beside them.

    Download keystone-topology-pack.zip holds everything (open topology-report.html and print it to PDF). topology.drawio opens in diagrams.net with every device and line carrying its data in Edit Data. Keep topology.json to add more devices later.
    Trace a path

      Preview only. vPC view: each vPC pair is one frame and each bundle spanning the pair is one line (vPC id, member count, rated speed). Physical view: every cable. IP view: devices that share a subnet, with the interface and address at each end and a table of every interface address under the picture. Speeds are transceiver or port ratings, not negotiated rates. Drag nodes in draw.io, then upload that file under Keep my layout next time.

      What to upload

      One capture per device is enough. Each capture should contain these commands (Cisco names shown; the Switch Analyzer collect lists already include most of them):

      • show cdp neighbors detail and show lldp neighbors detail - the links.
      • show etherchannel summary / show port-channel summary and show vpc - bundles and vPC pairs.
      • show inventory and show version - model, serial number and stack members.
      • show mac address-table and show ip arp - end hosts (optional).
      • show ip interface brief or the running configuration - management IP address.

      F5 BIG-IP: upload the .ucs archive (System > Archives > Create, or tmsh save sys ucs name). It holds the configuration only; add a tmsh capture of the same unit with show net interface and show net arp for port state, speed and ARP (F5 documentation: archives).

      The builder matches the two ends of each link by serial number, management IP and hostname, so a device that appears in a neighbor table is placed on the diagram even when you did not capture it (grey box).
