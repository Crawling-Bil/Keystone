# Keystone collect list - F5 BIG-IP DNS (GTM) (TMOS 12.1 - 17.x)
# For a unit provisioned with DNS (gtm): wide IPs, GTM pools, servers, data centers, listeners, iQuery, DNS profiles, DNS Express and DNSSEC. Log in with a read-only account, run the commands from tmsh or the advanced shell (bash), save the whole terminal buffer and upload it.
# Run it on every DNS device of the sync group: iQuery and monitor state differ per device. If the unit also runs LTM, add collect-lb-f5-bigip.txt to the same buffer.
# Every command only reads. A command that does not exist on your release prints an error and is skipped; leave it in the buffer. Lines that start with '#' are comments; remove the '#' of an optional command to run it.
# Also export a UCS (the weekly backup, unencrypted) of the unit and upload it next to this buffer.
# Before you share the buffer, search it for 'password', 'secret', 'passphrase', 'tsig' and '$M$' (encrypted values) and mask them.

# ---- Platform and health.
tmsh show sys version
tmsh show sys hardware
tmsh show sys provision
tmsh show sys software status
tmsh show sys ha-status
tmsh show sys cpu
tmsh show sys memory

# ---- Whole configuration: gtm, ltm, net, sys, auth and cm objects.
tmsh list

# ---- DNS settings that 'tmsh list' leaves out because they are defaults.
tmsh list gtm global-settings general
tmsh list gtm global-settings load-balancing
tmsh list ltm profile dns all-properties
tmsh list ltm virtual all-properties
tmsh list ltm virtual-address all-properties

# ---- DNS Express, resolvers and DNSSEC (zone names, key names and public keys only).
tmsh list ltm dns zone
tmsh list ltm dns nameserver
tmsh list ltm dns cache resolver
tmsh list ltm dns dnssec key
tmsh list ltm dns dnssec zone

# ---- High availability.
tmsh show cm sync-status
tmsh show cm failover-status
tmsh show cm device
tmsh show cm device-group

# ---- Live DNS state: feeds the Visualization and DNS (GTM) tabs.
tmsh show gtm wideip a detail
# tmsh show gtm wideip aaaa detail
# tmsh show gtm wideip cname detail
# tmsh show gtm wideip mx detail
# tmsh show gtm wideip srv detail
# tmsh show gtm wideip naptr detail
tmsh show gtm pool a detail
# tmsh show gtm pool a members detail
# tmsh show gtm pool aaaa detail
# tmsh show gtm pool cname detail
# tmsh show gtm pool srv detail
tmsh show gtm server detail
# tmsh show gtm server virtual-servers
tmsh show gtm datacenter
tmsh show gtm iquery
tmsh show gtm listener
# tmsh show gtm link

# ---- DNS traffic and services.
tmsh show ltm virtual
tmsh show ltm dns zone
tmsh show ltm dns cache resolver
tmsh show sys performance gtm
tmsh show sys performance dnsexpress
tmsh show sys performance dnssec
tmsh show net interface
