NETWORK ENGINEER SUITE WEB v1.7.1 - macOS

If the extracted folder is inside Work/Tools:
1. Open Terminal.
2. Type: cd 
3. Drag the extracted NES folder from Finder into Terminal, then press Return.
4. Run once:
   chmod +x setup_mac_linux.sh start_mac_linux.sh stop_mac_linux.sh verify_install.sh
   ./setup_mac_linux.sh
5. Start NES:
   ./start_mac_linux.sh
6. Open http://127.0.0.1:8002

To stop NES later:
./stop_mac_linux.sh
